# Glossary

| Term | Definition |
| --- | --- |
| PLC | Programmable Logic Controller, an industrial computer that reads inputs and drives outputs in a cyclic scan |
| HMI | Human-Machine Interface, the operator screen |
| SCADA | Supervisory Control and Data Acquisition, plant-wide supervision and data collection |
| P&ID | Piping and Instrumentation Diagram |
| I/O | Inputs and outputs of the PLC |
| Interlock | Condition that prevents an action when it is unsafe |
| Grafcet | Graphical method to describe sequential control (IEC 60848) |
| KPI | Key Performance Indicator |
| MTBF | Mean Time Between Failures |
| MTTR | Mean Time To Repair |
| FAT / SAT | Factory / Site Acceptance Test |
Sliding window (période glissante qui se termine à l’instant présent), Fault injection (forçage reproductible d’un défaut dans le modèle), Retentive memory (mémoire qui garde sa valeur à l’arrêt de l’automate), Self-clearing alarm (avertissement qui disparaît avec sa cause), Stabilization delay (délai avant de juger une mesure après un démarrage).

Runtime (programme qui exécute les écrans), HMI tag (variable de l’IHM reliée à une variable de l’automate), Acquisition cycle (période de lecture d’une variable), Text list (table valeur vers texte), Template (éléments communs à tous les écrans), HMI interface block (bloc de données qui sert d’unique interface entre automate et IHM).
