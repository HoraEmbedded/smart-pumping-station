# Figure generation tools

Figures are generated by code, so they stay reproducible and consistent with project parameters.

## Setup (Windows, PowerShell)

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r tools\requirements.txt

## Usage

    python tools\fig_block_diagram.py
    python tools\fig_volume_balance.py
    python tools\fig_pid.py

Outputs go to `02_design/diagrams/` (PNG, SVG, PDF).
