# Changelog

All notable changes are documented here. Format inspired by Keep a Changelog.

## [Unreleased]

## [0.1.0] - 2026-10-06

### Added
- Repository structure, hygiene files and bilingual README
- Workstation baseline, scope and simulation assumptions
- Decision log and roadmap

## [0.2.0] - 2026-10-06

### Added
- Figures generated by code: process block diagram, volume balance cycle, simplified P&ID
- Tank volume balance and reference cycle (33 min fill, 100 min drain, 0.45 starts per hour)
- I/O list (24 signals), alarm matrix (10 alarms, 2 warnings), alarm philosophy
- Use cases and roadmap aligned with the unified roadmap

## [0.3.0] - 2026-10-06

### Added
- 32 testable requirements with verification methods
- Requirements traceability matrix
- Test plan v0 (32 tests) written before PLC coding
- Parameter table (22 parameters) as single source of truth

## [0.4.0] - 2026-10-07

### Added
- State machine, transitions, allowed actions and critical interlocks (mode_state_description.md)
- Grafcet G1 (modes), supervisor G0 (stop and fault forcing) and G3 (automatic cycle), generated by code
- Derived requirements REQ-033 to REQ-037, tests T33 to T37, parameters P23 to P26
- Cycle time versus consumption analysis validating the frequent starts threshold

## [0.5.0] - 2026-10-10

### Added
- Manual and Maintenance modes with limited pump test
- Latched critical alarms (emergency stop, critical tank level, tank level sensor) and conditional reset
- Source availability with hysteresis
- Ladder blocks for alarm latching and indicators
- Eight new tests with evidence

### Changed
- Sources cleaned of internal references, blocks organized in groups
- Repository vocabulary: missions renamed to iterations

## [0.6.0] - 2026-10-10

### Added
- Second pump with automatic alternation after a normal cycle
- Backup pump when the priority pump is unavailable, including mid-cycle takeover
- Latched pump faults and a critical alarm when no pump is available
- One-pump-at-a-time interlock and restart delay verified
- Six new tests with evidence, regression of the single-pump tests

### Changed
- Level demand merged into the automatic cycle block

## [0.7.0] - 2026-10-11

### Added
- Low flow detection per pump with a stabilization delay and latched alarms
- Run feedback timeout treated as a pump fault
- High current warning, maintenance due warning, level not rising warning
- Frequent starts detection on a sliding window
- Station monitoring block and a single warning bit driving the amber lamp
- Fault injection in the process model
- Fault causes guide and V2 test report
- Eleven new tests, full regression of the previous tests

### Changed
- Retentive run hours and start counters

## [0.8.0] - 2026-10-13

### Added
- HMI device (WinCC RT Professional) connected to the PLC, simulated with Runtime Professional Simulation
- HMI interface data block and function block, operator commands from the HMI combined with the local inputs
- Common template with header and navigation, station overview and commands screens
- HMI design standard (palette, status always shown as text)
- Five new tests with evidence

### Changed
- Operator pump commands are cleared when the station leaves Manual or Maintenance

## [0.9.0] - 2026-10-16

### Added
- Flat export block with fixed layout, sample counter and simulated clock
- Simulated field signals in the process model
- Read only OPC UA collector, dataset schema and validator
- Six datasets: one normal and five fault scenarios with ground truth columns
- Data architecture, data dictionary, OPC UA setup notes and security measures
- Four new tests, regression of the previous tests

### Changed
- Frequent start window now follows simulated time

## [0.13.0] - 2026-10-18

### Added
- Explainable anomaly rules ANO_01 to ANO_06 with explanations carrying the values and the threshold crossed
- Evaluation against the injected faults, threshold margins, sensitivity table and figures for the six datasets
- Unit tests on constructed values, analysis of false positives and blind spots
- V5 test report
